# RGB-D bin picking grasp point detection

Программный модуль для сегментации объектов, определения порядка их разбора и расчёта параметров захвата на основе RGB-D данных.

## Возможности

- сегментация объектов на RGB-изображении с помощью Mask R-CNN;
- расчёт признаков объектов по RGB-D данным;
- приоритизация объектов и выбор объекта первого ранга;
- поиск точки захвата внутри выбранного объекта;
- расчёт параметров захвата: 2D-точка, 3D-точка, нормаль поверхности, вектор подхода и оценки качества;
- сохранение визуализации и JSON-результатов; 
- live-режим для камеры Intel RealSense.

- pyrealsense2

### Инструкция по установке

1. Клонировать репозиторий:

```
git clone https://github.com/m2110642/bin_picking_grasp.git
cd bin_picking_grasp 
```

2. Создать виртуальное окружение:
```
python -m venv venv
```

3. Активировать виртуальное окружение:
```
venv\Scripts\activate
```

4. Установить зависимсости: 
```
pip install -r requirements.txt
```

5. Скачать модель mask_rcnn_dataset1_best по ссылке https://drive.google.com/file/d/1XEoHL5j-TtbpgkjtSQEbb5iEwqcTvjxv/view?usp=sharing и поместить в папку models

## Запуск

### Offline-режим

Основной режим работы проекта выполняет обработку RGB-D сцен, сохранённых в папке `data`.

Для запуска:
```
python main.py
```

После выполнения результаты сохраняются в папку outputs.

### Live-режим
Дополнительно в проекте предусмотрен режим работы с камерой Intel RealSense.

Для запуска:
```
python live_demo.py
```

## Основные файлы

- `main.py` — основной запуск обработки сохранённых RGB-D сцен.
- `live_demo.py` — запуск режима работы с камерой Intel RealSense.
- `config.yaml` — настройки путей, модели и параметров алгоритма.
- `src/model_loader.py` — загрузка обученной модели Mask R-CNN.
- `src/segmenter.py` — сегментация объектов на RGB-изображении.
- `src/object_prioritizer.py` — расчёт признаков объектов и выбор объекта первого ранга.
- `src/grasp_detector.py` — поиск точки захвата внутри выбранного объекта.
- `src/grasp_parameters.py` — формирование итоговых параметров захвата.
- `src/visualizer.py` — сохранение визуализации результата.

## Выходные данные

После запуска `main.py` результаты сохраняются в папку `outputs`.

Для каждой обработанной сцены создаётся отдельная папка:

```text
outputs/
└── scene_01_.../
    ├── grasp_result.png
    ├── grasp_result.json
    └── top_grasp_candidates.json
```

Файл `grasp_result.png` содержит визуализацию результата:

- ранжирование найденных объектов;
- выбранный объект первого ранга;
- точку захвата;
- heatmap качества точек;
- Z-канал выбранного объекта.

Файл `grasp_result.json` содержит численные результаты обработки сцены:

- выбранный объект;
- найденную точку захвата;
- параметры захвата;
- количество рассмотренных кандидатов;
- путь к сохранённой визуализации.

Файл `top_grasp_candidates.json` содержит список лучших кандидатов точки захвата, отсортированных по значению `grasp_score`.

Также создаётся общий файл со сводкой по всем обработанным сценам:

```text
outputs/pipeline_summary.json
```

Файл `grasp_result.json` также содержит блок `grasp_parameters`, в котором сохраняются рассчитанные параметры захвата: выбранный объект, 2D-координаты точки, 3D-координаты в системе камеры, нормаль поверхности, вектор подхода и оценки качества найденной точки.

## Ограничения

В текущей версии проект рассчитывает параметры захвата по RGB-D данным, но не выполняет управление роботом.

Координаты точки захвата задаются в системе координат камеры. Для использования результата на реальном роботе требуется дополнительная калибровка камеры относительно робота и интеграция с конкретным захватным устройством.
